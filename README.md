# AI Team Monitor Pro

> 🏯 明代赛博朋克风格的AI团队实时监控面板

## 技术栈

| 层级 | 技术 | 选型理由 |
|------|------|----------|
| 前端框架 | React 18 + TypeScript | 组件化开发，类型安全 |
| 3D渲染 | Three.js + React Three Fiber | 3D办公室场景，声明式3D开发 |
| 状态管理 | Zustand | 轻量，支持订阅选择器 |
| 样式 | TailwindCSS | 原子化CSS，快速迭代 |
| 构建 | Vite 5 | 极速HMR，开箱即用 |
| 后端 | Node.js + Express | 轻量，前后端同语言 |
| 实时通信 | Socket.io | 双向通信，自动重连 |
| 数据存储 | 内存（初期） | 快速原型，后续可迁移 |

## 数据流

```
Agent行为引擎 → 状态变更 → State Manager → Socket.io广播 → Zustand更新 → UI重渲染
                                  ↓
                             活动日志记录
                                  ↓
                           Balance追踪更新
```

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发环境（前后端同时启动）
npm run dev

# 前端单独启动
npm run dev:client

# 后端单独启动
npm run dev:server

# 构建
npm run build
```
